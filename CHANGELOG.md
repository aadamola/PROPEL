## 2026-09-15 — Instagram keyword automation built for Shalom Park (24 rules, 40 new tests)

- **The architectural decision: keywords are a fast lane IN FRONT of the brain, not a replacement.** An exact rule match returns pre-written, human-approved text with no model call — ₦0, no latency, **no hallucination surface**. A miss falls through to the Concierge CORE, which still has the KB and the guardrails. Same doctrine as docs/13's "arithmetic never goes to a language model": an answer whose exact words we already know should never be regenerated. **Both lanes exit through the same guardrail node**, so a well-meaning edit to the rule sheet that smuggles in a yield promise is caught at runtime, not only at build time.
- **The safety class is the whole design.** Nine `escalate_only` rules — returns, refund, bank details, discount, litigation, completion date, other charges, agency, mortgage — **outrank every commercial rule when both match**. Without that one line, *"what rental yield does the 4 bedroom give"* fires the ₦185m price card and answers a returns question with a price. With it, that buyer reaches a human with no figure attached. It is the most important line in the system and it has a starred test.
- **🔴 The ₦95m condo price is deliberately absent.** `SP-2B` describes the product and its availability and hands the price to a human. The figure carries an unresolved Propel price query, and an automation would publish a suspected-wrong price to *every* commenter before anyone noticed. A test fails the build if the number appears anywhere in the table. **One-line fix the day Collins confirms it** — which is now a revenue blocker, not admin.
- **Public replies carry no numbers and no title claims — enforced by the linter.** A public comment is *publication*: permanent, screenshot-able, un-editable, and the title documents are still unsighted (Gate 2). A DM is *conversation* and may carry warranted facts. That distinction is now code: `build-keywords.js` rejects any public reply containing a digit.
- **Meta's limits enforced in code, not in hope:** one private reply per comment (keyed on comment id, redelivery refused) · 7-day window · 180 automated DMs/hour against Meta's ~200, with **overflow held for a human rather than dropped** — a buyer who gets a late human answer is still a lead; a buyer who gets nothing is not.
- **Attribution built in at the keyword level.** Every rule carries a ref code that rides in the wa.me prefilled text, so a buyer's first WhatsApp message identifies the exact Instagram keyword that produced them. That is what turns "Instagram works" into a commission claim on a ₦185m unit.
- **Links ship OFF by default (`mode: none`).** The `human_line` option would point an automation at Collins' personal phone at volume — **Shalom Park's call, not ours.** A test guarantees no half-formed URL ever ships; with no number configured the DM ends "Reply here and the team will pick it up."
- **Delivered:** the rule table as a **Google Sheet in ADEDAMOLA's Drive** (24 rows, verified) mirrored as `clients/shalom-park/keywords.csv` · `ops/concierge/lib/keywords.js` (token-based matcher — "land" never matches "Ireland"; folds `4bed`/`four bedroom`/`hw much`/`wetin be the price`) · `05-channel-instagram.json` (20 nodes, HMAC-verified, signature → normalise → fast lane → guardrail → send) · `tools/build-keywords.js` (compiler + linter) · `tools/test-keywords.js` (30) + `tools/test-ig-workflow.js` (10, run against the *shipped* workflow JSON).
